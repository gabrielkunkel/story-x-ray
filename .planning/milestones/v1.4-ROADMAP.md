### Phase 18: PWA Install Prompt
**Goal:** Chrome users can install the app from a native-feeling callout that appears after their first story, with progressive re-prompting for dismissals and permanent suppression after installation.
**Requirements:** PWA-01, PWA-02, INSTALL-01–06

**Success Criteria (all met):**
1. Chrome's install criteria fully met — `beforeinstallprompt` fires in production build ✅
2. After first story, callout appears on workspace pointing to Chrome URL bar ✅
3. Dismissal saves timestamp; re-prompts after 3d → 7d → 30d → permanent suppress ✅
4. After install (`appinstalled` event), callout never shown again ✅
5. Non-Chrome browsers: no callout, no install messaging ✅

## Key Accomplishments

1. **Maskable icon** — Added `purpose: 'any maskable'` to 512px icon; Chrome installability criteria now fully met
2. **`beforeinstallprompt` capture at root** — Hook placed in `App.tsx` to avoid event timing miss before workspace mounts
3. **Progressive dismiss cooldown** — `sxr:pwa:dismiss` localStorage key tracks count + timestamp for 3d/7d/30d schedule
4. **Permanent install suppress** — `sxr:pwa:installed` set on `appinstalled` event; callout never shown to installed users
5. **Chrome-only guard** — `navigator.userAgentData.brands` detection (+ UA fallback) blocks callout on Edge, Safari, Firefox
6. **Inline callout design** — Non-modal banner matching `diag-capture-cta` visual pattern; no `prompt()` call, points to address bar
