## PDF Export Overhaul (PDF2)

- [x] **PDF2-01**: User can trigger a PDF export from the export dropdown with an option to include or exclude scores
  - _Outcome: Delivered via PdfExportModal two-button choice (With/Without Scores)_
- [x] **PDF2-02**: Generated PDF is a real downloadable file (not a browser print dialog), produced by jsPDF + autoTable
  - _Outcome: Delivered; window.print() fully removed_
- [x] **PDF2-03**: PDF header shows story title, author, genre, and export date
  - _Outcome: Delivered; empty fields omitted with · separator_
- [x] **PDF2-04**: PDF body is a table with columns: Step #, Label, Act, Beat Text, Notes (always shown)
  - _Outcome: Delivered; portrait 5-column layout_
- [x] **PDF2-05**: When "include scores" is selected, the table adds columns: Connection, Pressure, Hope, Stability (actual), Target values, and Delta (actual − target) per dimension
  - _Outcome: Delivered; landscape 17-column layout with Actual/Target/Delta per dimension_
- [x] **PDF2-06**: All 16 steps appear in the table; empty beat text and notes cells are left blank
  - _Outcome: Delivered; confirmed in visual inspection_
- [x] **PDF2-07**: Table spans multiple pages cleanly with column headers repeated on each page
  - _Outcome: Delivered; showHead: 'everyPage' configured_

## List View Card Polish (CARD)

- [x] **CARD-01**: In list view on wide screens (where the italic beat excerpt is visible to the right), the purple filled dot is hidden
  - _Outcome: Delivered via .story-card--list .story-card__filled { display: none }_
- [x] **CARD-02**: On narrow screens (where the beat excerpt collapses below the step info), the purple dot is shown as before to signal card has content
  - _Outcome: Delivered via @media (max-width: 520px) override restoring display: block_
- [x] **CARD-03**: On wide screens, the italic beat excerpt is right-aligned within the remaining card space (flex end / text-align right)
