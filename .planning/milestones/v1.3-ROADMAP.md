# Milestone Archive — v1.3 Export Polish & Card UX

**Shipped:** 2026-04-05
**Phases:** 15–17
**Requirements:** 14/14 covered
**Audit:** PASSED

---

## Milestone Goal

Replace the broken single-page PDF with a real multi-page jsPDF table export, consolidate all exports into a single dropdown, and clean up list-view card presentation on wide screens.

---

## Accomplishments

1. **Real PDF download** — replaced `window.print()` with jsPDF + autoTable; generates a true `.pdf` file with no browser dialog
2. **Portrait PDF (Without Scores)** — 5 columns: Step, Label, Act, Beat Text, Notes; header with title/author/genre/date
3. **Landscape PDF (With Scores)** — 17 columns adding Connection/Pressure/Hope/Stability Actual, Target, and Delta per dimension
4. **Multi-page table** — column headers repeat on every page (`showHead: 'everyPage'`)
5. **Export dropdown** — single "Export ▾" button replaces 4 individual export buttons; houses PDF, Fountain, JSON, Markdown
6. **List view card polish** — purple dot hides on wide screens when beat excerpt is visible; right-aligns excerpt; dot restores on narrow screens
