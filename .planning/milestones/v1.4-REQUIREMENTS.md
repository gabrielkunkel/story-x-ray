## PWA Installability (PWA)

- [x] **PWA-01**: The web app manifest includes at least one icon with `purpose: "maskable"` — **Implemented:** `vite.config.ts` 512px icon entry
- [x] **PWA-02**: `beforeinstallprompt` fires in Chrome during production build — **Verified:** Chrome address bar install icon confirmed

## Install Prompt (INSTALL)

- [x] **INSTALL-01**: Prompt only appears when `beforeinstallprompt` has fired — **Implemented:** `isInstallable` prop gates the effect
- [x] **INSTALL-02**: First shown after user creates first story — **Implemented:** Only rendered in `StoryWorkspacePage`
- [x] **INSTALL-03**: Simple callout pointing to Chrome URL bar with benefit statement — **Implemented:** `PWAInstallCallout` inline banner, no `prompt()` call
- [x] **INSTALL-04**: Dismissal saves timestamp; re-prompts at 3d → 7d → 30d → permanent — **Implemented:** `sxr:pwa:dismiss` localStorage key
- [x] **INSTALL-05**: After install, prompt permanently suppressed — **Implemented:** `sxr:pwa:installed` set on `appinstalled` event
- [x] **INSTALL-06**: Non-Chrome browsers show no install UI — **Implemented:** `isChromeBrowser()` guard
