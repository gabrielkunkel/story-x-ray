## Interaction Contract

This section is the primary design specification for Phase 22.

### Trigger States

The email modal (`EmailCaptureModal` with `context='act1'`) has three valid trigger states after the 4-beat threshold is met:

| State | Condition | Modal Fires? |
|-------|-----------|-------------|
| Active typing | onChange fires in beat textarea OR notes textarea of open CardEditor | No — timer resets |
| Card navigation | User clicks a different story card (activeStepNumber changes) | No — timer resets |
| Idle timeout | No onChange or card navigation for 10 seconds after threshold met | Yes |
| Qualifying blur | Beat textarea of the specific step that completed the 4th beat loses focus due to leaving app context | Yes — immediately |
| Already shown | `hasShownThisSession('act1')` returns true | Never — blocked |

### Qualifying Field Definition

The "qualifying field" is the beat textarea of the specific `stepNumber` whose `beatText` entry pushed `filledBeats >= 4`. This reference must be retained in a ref across card navigation.

### Blur Trigger Scope

The immediate-blur trigger fires ONLY when the qualifying field's beat textarea loses focus to an element OUTSIDE the board (tab switch, window blur, click on non-board element). Card-to-card navigation does NOT constitute a qualifying blur.

Implementation note (Claude's discretion per CONTEXT.md D-02): Use `relatedTarget` on the blur event, or a `isNavigatingCards` flag set/cleared around card click handlers, to distinguish app-external blur from in-app navigation blur. The planner decides the mechanism.

### Timer Behavior

- Timer starts when `filledBeats >= 4` for the first time this session
- Every `onChange` in beat OR notes textarea resets the 10s countdown
- Every card navigation event (activeStepNumber change) resets the 10s countdown
- Timer fires `setCaptureContext('act1')` + `markShownThisSession('act1')` at expiry
- Timer is cleared on component unmount (cleanup)
- Once `hasShownThisSession('act1')` is true, timer and blur handler are both disabled

### Focus Ring Contract

Beat textarea focus state: `border-color: var(--accent)` + `box-shadow: 0 0 0 3px var(--accent-bg)`.

Source: `src/index.css` textarea `:focus` rule — already established; no change needed.
