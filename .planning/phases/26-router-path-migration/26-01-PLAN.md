<objective>
Replace BrowserRouter with HashRouter in src/App.tsx so the app navigates correctly on GitHub Pages static hosting — no 404s on direct URL access or page refresh.

Purpose: GitHub Pages serves static files only; BrowserRouter relies on server-side URL rewriting for routes like /setup and /story/:id, which returns 404 on static hosts. HashRouter encodes routes as URL fragments (e.g. /#/setup), bypassing the server entirely.

Output: Updated src/App.tsx with HashRouter. Verified zero root-absolute paths in source files.
</objective>

No auth or session data is derived from the fragment. |
| T-26-02 | Tampering | src/App.tsx route table | accept | Route definitions are static source code; no dynamic route construction from user input. The catch-all redirect prevents unmatched paths from rendering unexpected state. |
