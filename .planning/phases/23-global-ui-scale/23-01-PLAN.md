<objective>
Scale the app's visual density upward so it reads comfortably at default browser zoom. Root font size moves from 16px to 17px. A targeted pass converts density-affecting typography and spacing from hardcoded px to rem so they scale with the root. Precision values (borders, hairlines, chart strokes) stay in px. Two layout anchors receive modest bumps: card editor sidebar and board grid column minimum.

Purpose: Writers currently work at default zoom with text that feels slightly small. This change gives the app the feel of approximately "Chrome at 110%" without requiring users to manually adjust zoom.

Output: Modified `src/index.css` (root font, rem conversions, width bumps) and `src/components/WaveformGraph.tsx` (chart tick font size bump).
