Add a beat text preview toggle to the board header and render italic beat excerpts on story cards when enabled.

Purpose: Writers can quickly scan which steps have beat text and read brief excerpts without opening the side editor, making the board a more useful at-a-glance reference.

Output: BoardHeader gains a preview eye toggle. StoryCard conditionally renders an italic, truncated beat preview. ActColumn passes the prop through. StoryWorkspacePage manages the state and persists to localStorage.

**1. StoryWorkspacePage.tsx — add showBeatPreview state:**

Add state initialized from localStorage:
```tsx
const [showBeatPreview, setShowBeatPreview] = useState<boolean>(() => {

})
```

```tsx
function handleToggleBeatPreview() {
  setShowBeatPreview(prev => {

    localStorage.setItem('sx:showBeatPreview', String(next))
```
