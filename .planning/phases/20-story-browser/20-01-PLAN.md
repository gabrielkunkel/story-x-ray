# Plan 20-01: Story List on StartPage

## Goal

Replace the single "Continue Story" button with a full list of all saved stories, ordered by most recently updated. Each story is clickable to open its workspace.

## Context

`loadAllStories()` already exists in `storage.ts` and returns the full stories array. `deleteStory(id)` also exists. The StartPage currently shows "Continue Story" only if `activeId` is set — this is too limited for users with multiple projects.

**Files to modify:**
- `src/pages/StartPage.tsx` — add story list, remove "Continue Story" button, import `loadAllStories`
- `src/index.css` — add `.story-list` styles

**No new dependencies.**

---

## Wave 1 — Data + Component Structure

### Task 20-01-01: Load and sort stories in StartPage

**File:** `src/pages/StartPage.tsx`

**Change:** Replace `getActiveStoryId()` import with `loadAllStories()`. Load all stories sorted by `updatedAt` descending. Remove the `activeId` / "Continue Story" button.

```typescript
// Remove:
import { getActiveStoryId } from '../services/storage'
// Add:
import { loadAllStories } from '../services/storage'

// In component:
const stories = loadAllStories().sort(
  (a, b) => new Date(b.updatedAt).getTime() - new Date(a.updatedAt).getTime()
)
```

Remove the "Continue Story" `{activeId && ...}` block from JSX.

**Commit:** `feat(stories): load all stories sorted by recency on StartPage`

## Wave 2 — UI

### Task 20-01-02: Render story list

**File:** `src/pages/StartPage.tsx`

Add the story list below `.start-actions` and above `.start-ctas`:

```tsx
{stories.length > 0 && (
  <div className="story-list">
    <p className="story-list__label">Your stories</p>
    <ul className="story-list__items">
      {stories.map(story => (
        <li key={story.id} className="story-list__item">
          <button
            className="story-list__open"
            onClick={() => navigate(`/story/${story.id}`)}
          >
            <span className="story-list__title">{story.title || 'Untitled'}</span>
            <span className="story-list__date">
              {new Date(story.updatedAt).toLocaleDateString(undefined, { month: 'short', day: 'numeric', year: 'numeric' })}
            </span>
          </button>
        </li>
      ))}
    </ul>
  </div>
)}
```

**Commit:** `feat(stories): render story list on StartPage (STORIES-01, STORIES-02, STORIES-03)`
