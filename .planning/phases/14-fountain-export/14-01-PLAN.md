# Plan 14-01 — Fountain Screenplay Export

## Goal
Add `exportStoryAsFountain()` to `export.ts`, wire up a "↓ Fountain" button in the board header, and download a `.fountain` file compatible with Final Draft.

## Requirements Addressed
FTN-01, FTN-02, FTN-03, FTN-04

## Fountain Format

Fountain is plain-text with simple markup. For beats:

```
Title: Romeo & Juliet (Example)
Author: William Shakespeare
Draft Date: April 5, 2026

===

# Act I

## Step 01: Safe Baseline

Two households, both alike in dignity — Romeo Montague and Juliet Capulet live in a world of rigid order and family loyalty. Love seems impossible but safety feels certain.

## Step 02: Tension Emerges

...

# Act IIA

...
```

- Title page: `Title:`, `Author:` (if set), `Draft Date:`, then `===`
- Act headings: `# Act I` (Fountain section)
- Step headings: `## Step NN: Label` (Fountain sub-section)
- Beat text: plain action paragraph
- Steps with no beat text: omitted entirely

## Files to Change

### 1. `src/utils/export.ts`

Add `exportStoryAsFountain` after `exportStoryAsMarkdown`:

```ts
export function exportStoryAsFountain(story: Story): void {
  const lines: string[] = []

  // Title page
  lines.push(`Title: ${story.title}`)
  if (story.author) lines.push(`Author: ${story.author}`)
  lines.push(`Draft Date: ${new Date().toLocaleDateString(undefined, { year: 'numeric', month: 'long', day: 'numeric' })}`)
  lines.push('')
  lines.push('===')
  lines.push('')

  // Group steps by act
  const ACT_ORDER = ['I', 'IIA', 'IIB', 'III'] as const
  const ACT_LABELS: Record<string, string> = {
    I: 'Act I', IIA: 'Act IIA', IIB: 'Act IIB', III: 'Act III',
  }

  for (const act of ACT_ORDER) {
    const actSteps = story.steps.filter(s => s.act === act && s.beatText.trim())
    if (actSteps.length === 0) continue

    lines.push(`# ${ACT_LABELS[act]}`)
    lines.push('')

    for (const step of actSteps) {
      const num = String(step.stepNumber).padStart(2, '0')
      lines.push(`## Step ${num}: ${step.label}`)
      lines.push('')
      lines.push(step.beatText.trim())
      lines.push('')
    }
  }

  const fountain = lines.join('\n')
  const blob = new Blob([fountain], { type: 'text/plain' })
  const url = URL.createObjectURL(blob)
  const a = document.createElement('a')
  a.href = url
  a.download = `${sanitizeFilename(story.title)}.fountain`
  a.click()
  URL.revokeObjectURL(url)
}
```
