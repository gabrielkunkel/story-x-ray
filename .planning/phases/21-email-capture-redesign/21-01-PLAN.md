# Plan 21-01: Trigger Logic Change + Configurable Copy

## Goal

Change the email capture trigger from "all Act I beats filled" to "any 4 beats filled across the whole story," and mark the copy constants with a clear config comment block so they are easy to find and edit.

## Scope

**In scope:**
- `src/pages/StoryWorkspacePage.tsx` — replace Act I trigger useEffect with 4-beat threshold
- `src/components/EmailCaptureModal.tsx` — update `'act1'` headline copy, add marketing config comment block, add `MODAL_IMAGE_SRC` constant (empty string default)

**Out of scope:**
- Image rendering in modal JSX (Plan 02)
- CSS for image element (Plan 02)
- README documentation (Plan 02)
- Changes to `src/utils/emailCapture.ts` (no changes needed)
- Renaming the `'act1'` session key or `CaptureContext` type value

### Wave 1: Trigger logic and copy update

#### Task 21-01-01: Replace Act I trigger with 4-beat threshold
**File:** `src/pages/StoryWorkspacePage.tsx`
**Requirement:** CAPTURE-01, CAPTURE-02

**Change:** In `StoryWorkspacePage.tsx`, replace the trigger useEffect block (lines 53-74) with the new 4-beat threshold logic:

1. Rename `act1CheckedRef` to `beatThresholdCheckedRef` (line 53)
2. Update the comment from `// Trigger 1 — Post-Act-I popup` to `// Trigger 1 — 4-beat threshold popup` (line 64)
3. Replace the body of the useEffect:
   - Remove: `const act1Steps = story.steps.filter(s => s.act === 'I')`
   - Remove: `if (act1Steps.every(s => s.beatText.trim().length > 0))`
   - Add: `const filledBeats = story.steps.filter(s => s.beatText.trim().length > 0).length`
   - Add: `if (filledBeats >= 4)`
4. Update the ref check from `act1CheckedRef.current` to `beatThresholdCheckedRef.current` (in the early return and the assignment)
5. Keep `hasShownThisSession('act1')`, `markShownThisSession('act1')`, and `setCaptureContext('act1')` unchanged — the `'act1'` key is intentionally preserved to avoid double-show for existing sessions

The resulting useEffect should be:
```typescript
const beatThresholdCheckedRef = useRef(false)

// Trigger 1 — 4-beat threshold popup
useEffect(() => {
  if (!story || beatThresholdCheckedRef.current) return
  if (hasSubmittedEmail() || hasShownThisSession('act1')) return
  const filledBeats = story.steps.filter(s => s.beatText.trim().length > 0).length
  if (filledBeats >= 4) {
    beatThresholdCheckedRef.current = true
    markShownThisSession('act1')
    setCaptureContext('act1')
  }
}, [story])
```
