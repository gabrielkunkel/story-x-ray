# Plan 21-02: Marketing Image Support in Modal

## Goal

Render an optional marketing image above the modal headline when `MODAL_IMAGE_SRC` is configured, add the supporting CSS, and document the full modal customization process in README.md.

## Scope

**In scope:**
- `src/components/EmailCaptureModal.tsx` — conditional image element in JSX
- `src/index.css` — `.capture-modal__image` styles
- `README.md` — "Customize email modal" documentation section

**Out of scope:**
- Trigger logic (completed in Plan 01)
- Copy constant changes (completed in Plan 01)
- Providing an actual marketing image file (user supplies their own)

## Security Threat Model

<threat_model>
**ASVS Level:** L1

| Threat | Likelihood | Impact | Mitigation |
|--------|-----------|--------|------------|
| `MODAL_IMAGE_SRC` set to external URL — potential tracking pixel or mixed content | Low | Low | Accept — constant is developer-controlled source code, not user input; README recommends local `/public` paths |
| Large image file causes slow modal render | Low | Low | Accept — developer chooses the image; README recommends dimensions |
| Image 404 shows broken image icon | Low | Low | Mitigate — conditional render `{MODAL_IMAGE_SRC && <img />}` ensures no element when empty; README documents to verify file exists |

**High-severity threats:** none
**Blocking issues:** none
</threat_model>

## Tasks

### Wave 1: Image rendering and styles

#### Task 21-02-01: Add conditional image to modal JSX and CSS
**Files:** `src/components/EmailCaptureModal.tsx`, `src/index.css`
**Requirement:** CAPTURE-03

**Change in `EmailCaptureModal.tsx`:**

1. Add import for `MODAL_IMAGE_SRC` at the top of the component's render section. Since `MODAL_IMAGE_SRC` is defined in the same file (from Plan 01), no import is needed — it is already in scope.

2. In the JSX, insert the conditional image element between the close button and the headline paragraph (between lines 64 and 66 of the current file). Add immediately before `<p className="capture-modal__headline">`:
   ```tsx
   {MODAL_IMAGE_SRC && (
     <img
       className="capture-modal__image"
       src={MODAL_IMAGE_SRC}
       alt=""
       aria-hidden="true"
     />
   )}
   ```
   The `alt=""` with `aria-hidden="true"` is correct for a decorative marketing image.

**Change in `src/index.css`:**

3. Add the `.capture-modal__image` rule immediately after the `.capture-modal__close` block (after line 1086, before `.capture-modal__headline`):
   ```css
   .capture-modal__image {
     width: 100%;
     border-radius: 8px;
     display: block;
     margin-bottom: 4px;
   }
   ```

</verify>

#### Task 21-02-02: Add "Customize email modal" section to README.md
**File:** `README.md`
**Requirement:** CAPTURE-05

**Change:** Add a new section after the existing "Enable Beehiiv email capture" section. The new section should be:

```markdown
## Customize email modal

The email capture modal's marketing content is configured in  
`src/components/EmailCaptureModal.tsx` — look for the **Marketing config** comment block near the top of the file.

### Add a marketing image

1. Place your image in the `public/` directory (e.g. `public/marketing.png`)
2. Set the path in `EmailCaptureModal.tsx`:
   ```ts
   export const MODAL_IMAGE_SRC = '/marketing.png'
   ```
3. Leave `MODAL_IMAGE_SRC = ''` to hide the image

**Recommended dimensions:** 688 px wide (2x for retina), aspect ratio ~16:9 or ~3:1 (banner-style).

### Update headline and body copy

Edit the `COPY` record in the same config block. The `'act1'` entry controls the copy shown when the modal triggers after 4 beats are filled:

```ts
'act1': {
  headline: 'Your story is taking shape.',
  body: 'Get 5 example story maps, a beat gap checklist, and the structure rescue guide. Free.',
},
```

Other entries (`'export'`, `'diagnostics'`, `'examples'`, `'early-access'`) control copy for their respective trigger contexts.
```
