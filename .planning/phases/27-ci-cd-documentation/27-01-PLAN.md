  <action>
Create the directory structure `.github/workflows/` and write `deploy.yml` with the following exact content (no deviations — every field maps to a requirement):

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

concurrency:
  group: pages
  cancel-in-progress: true

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm

      - name: Install dependencies
        run: npm ci

      - name: Build
        run: npm run build:prod

      - name: Upload Pages artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: dist

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

Key implementation notes:
- `on.push.branches: [main]` satisfies CI-01 (push trigger)
- `on.workflow_dispatch` satisfies CI-01 (manual trigger)
- `concurrency.group: pages` + `cancel-in-progress: true` satisfies CI-05
- `permissions.contents: read`, `pages: write`, `id-token: write` satisfies CI-02
- Split `build` and `deploy` jobs satisfies CI-02
- `npm run build:prod` satisfies CI-03 (calls tsc -b && vite build --mode gh-pages)
- `actions/upload-pages-artifact@v3 path: dist` satisfies CI-03
- `actions/deploy-pages@v4` + `environment: github-pages` satisfies CI-04
- Use `node-version: 20` (LTS) and `npm ci` (not npm install) for reproducible installs
- No manual env var injection — `.env.gh-pages` is committed and Vite reads it via --mode gh-pages
