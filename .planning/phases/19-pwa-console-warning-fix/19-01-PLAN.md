# Plan 19-01: Remove preventDefault from beforeinstallprompt handler

## Goal

Eliminate the Chrome console warning "Banner not shown: beforeinstallprompt.preventDefault() called. The page must call beforeinstallprompt.prompt() to show the banner." by removing the `e.preventDefault()` call we don't need.

## Context

`e.preventDefault()` on `beforeinstallprompt` tells Chrome to suppress its native install mini-infobar/banner. This is the correct approach when you intend to call `deferredPrompt.prompt()` yourself at a chosen moment. But our design (INSTALL-03) points users to the Chrome address bar install button — we never call `prompt()`. Calling `preventDefault()` without ever calling `prompt()` causes the warning.

Removing `preventDefault()` means Chrome may show its own mini-infobar alongside our callout in some versions, but:
1. Chrome's mini-infobar is largely deprecated in recent Chrome versions (the address bar icon is the primary UI)
2. Our callout is still shown (gated by `isInstallable`, which is set when the event fires)
3. The console warning disappears

**File:** `src/hooks/usePWAInstall.ts` — remove `e.preventDefault()` from `handleBeforeInstall`

## Wave 1

### Task 19-01-01: Remove e.preventDefault()

**File:** `src/hooks/usePWAInstall.ts`

**Change:**
```typescript
// BEFORE
function handleBeforeInstall(e: Event) {
  e.preventDefault()
  deferredPrompt.current = e as BeforeInstallPromptEvent
  setIsInstallable(true)
}

// AFTER
function handleBeforeInstall(e: Event) {
  deferredPrompt.current = e as BeforeInstallPromptEvent
  setIsInstallable(true)
}
```
