## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Close-proximity inline gaps (e.g. button icon gap: 6px — see exception) |
| sm | 8px | Tight groupings, button row gap |
| md | 16px | Default element spacing, modal internal gap |
| lg | 24px | Modal padding, section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Button `gap: 6px` is the project-established pattern from `.btn-primary` and `.btn-ghost` — use 6px for icon-label gap inside buttons (not 4px or 8px)

- Overlay padding: 24px all sides (matches `.capture-overlay`)

Source: `src/index.css` lines 85–160 (button definitions) and 1130–1158 (story-info-modal).

## Component Specification: PdfExportModal

This is the only new UI surface in Phase 15.

### Structure

```
.capture-overlay          ← existing shared overlay class (fixed inset, backdrop)
  .pdf-export-modal       ← new modal card
    h2.pdf-export-modal__heading    "Export PDF"
    .pdf-export-modal__actions      ← two-button row
      button.btn-primary            "Without Scores"
      button.btn-ghost              "With Scores"
```

### Layout rules

- Modal card: `max-width: 340px`, `width: 100%`, centered in overlay
- Modal card padding: `24px 24px 20px` (matches `.story-info-modal`)
- Modal card border: `1.5px solid var(--border)`, `border-radius: 12px`
- Modal card background: `var(--bg)`
- Modal card shadow: `var(--shadow)`
- Heading margin: 0 (global h2 rule handles this)
- Actions row: `display: flex`, `gap: 8px`, `justify-content: flex-end`, `padding-top: 8px`

### Button assignment

| Button | Class | Label | Behavior |
|--------|-------|-------|----------|
| Primary CTA | `.btn-primary` | Without Scores | Calls `onChoose(false)` — portrait 5-column PDF |
| Secondary | `.btn-ghost` | With Scores | Calls `onChoose(true)` — landscape 17-column PDF |

Rationale: "Without Scores" is the simpler, faster-understood option and serves the majority use case (clean screenplay outline). It gets primary emphasis. "With Scores" is the power-user path and gets ghost treatment, consistent with Cancel/Confirm patterns elsewhere.

### Overlay behavior

- Click outside modal card (`e.target === e.currentTarget`) calls `onClose()`
- No close (×) button required — the overlay click-away is sufficient for a two-choice modal
- Modal closes automatically after PDF generation (D-09) — no success/loading state needed
- No animation required — existing overlay pattern has no entry animation

### Accessibility

- `role="dialog"` on `.pdf-export-modal`
- `aria-modal="true"` on `.pdf-export-modal`
- `aria-label="Export PDF"` on `.pdf-export-modal`
- Focus lands on the "Without Scores" button (`autoFocus`) on modal open
- Both buttons are keyboard-operable via Tab + Enter/Space (native `<button>`)
- Overlay backdrop has `tabIndex={-1}` to prevent focus trap escape via click-outside

## PDF Document Visual Contract

The PDF is a downloaded file, not a UI component. These values are design constraints for the executor implementing `exportStoryAsPDF`.

### Header (drawn above table)

| Element | Spec |
|---------|------|
| Story title | Helvetica Bold, 16pt, top-left at 14mm margin |
| Meta line | Helvetica Regular, 10pt, 7mm below title; format: `Author · Genre · Exported Month DD, YYYY`; omit empty author/genre fields |
| Horizontal rule | 0.3mm line weight, full width between margins, 5mm below meta line |
| Table start Y | 5mm below rule (total header height ~22mm from top) |

### Table (Without Scores — portrait A4)

| Property | Value |
|----------|-------|
| Orientation | Portrait |
| Page size | A4 (210mm × 297mm) |
| Side margins | 14mm each side (182mm usable width) |
| Font size | 9pt body, column headers bold |
| Cell padding | 2mm |
| Cell overflow | linebreak |
| Theme | grid |
| Header fill | RGB(80, 40, 120) — deep purple |
| Header text | white (#fff), bold |
| Column headers | Step / Label / Act / Beat Text / Notes |
| Column widths | Step: 12mm, Label: 30mm, Act: 18mm, Notes: 50mm, Beat Text: auto (remainder ~72mm) |
| Headers per page | every page (`showHead: 'everyPage'`) |

### Table (With Scores — landscape A4)

| Property | Value |
|----------|-------|
| Orientation | Landscape |
| Page size | A4 (297mm × 210mm) |
| Side margins | 14mm each side (269mm usable width) |
| Font size | 7pt body, 6pt column headers |
| Cell padding | 1.5mm |
| Cell overflow | linebreak |
| Theme | grid |
| Header fill | RGB(80, 40, 120) — deep purple |
| Header text | white (#fff), bold |
| Column headers | Step / Label / Act / Beat Text / Notes / Conn A / Conn T / Conn Δ / Pres A / Pres T / Pres Δ / Hope A / Hope T / Hope Δ / Stab A / Stab T / Stab Δ |
| Column widths | Step: 12mm, Label: 28mm, Act: 18mm, Beat Text: 30mm, Notes: 25mm, each score col: 13mm (12 cols = 156mm); total: 269mm |
| Score columns alignment | center |
| Headers per page | every page (`showHead: 'everyPage'`) |

### Data display rules

| Rule | Value |
|------|-------|
| Step number | Zero-padded: `01` through `16` |
| Act label | Full form: `Act I`, `Act IIA`, `Act IIB`, `Act III` |
| Empty beatText | Blank cell (empty string — no em dash, no placeholder) |
| Empty notes | Blank cell (empty string — no em dash, no placeholder) |
| Actual score = 0 | Display as `—` (em dash) |
| Target score | Always display numeric value |
| Delta format | `+N` / `-N` / `—` (em dash when delta = 0) |

Source: CONTEXT.md D-04 through D-15; RESEARCH.md Pattern 3, 4, 5.
